Telegram Credentials Guide

Step-by-step instructions to obtain your keys

The API ID and API Hash authenticate your Telethon client to Telegram's core network.
  1. Open my.telegram.org in your browser.
  2. Enter your phone number (with country code) and submit the verification code sent to your Telegram app.
  3. Click on API development tools.
  4. Fill in App title (e.g. JVault Gateway) and Short name (e.g. jvault). Select Desktop or Web as platform.
  5. Click Create application.
  6. Copy your numeric App api_id into the Telegram API ID field, and your 32-character App api_hash into the Telegram API Hash field.
The Bot Token links your automated checkout responder to your dedicated Telegram bot.
  1. Open Telegram and search for @BotFather (official verified bot).
  2. Click Start and send the command: /newbot
  3. Choose a friendly display name for your bot (e.g. JVault Checkout Bot).
  4. Choose a unique username ending in bot (e.g. MyJVaultPay_bot).
  5. BotFather will generate your HTTP API token (e.g. 123456789:ABCdefGHIjklmno...).
  6. Copy and paste the entire token string into the Bot Token field in JVault Settings.
